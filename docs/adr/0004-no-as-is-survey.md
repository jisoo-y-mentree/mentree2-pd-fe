# ADR-0004: 리뉴얼의 as-is 조사를 하지 않는다

- 상태: 승인
- 날짜: 2026-08-31

## 문맥

`screen-inventory` 는 「현행에 있고 남긴다 → `계승` / 버린다 → `폐지` / 없다 → `신규`」의 3분류를 필수로 걸고 있었다. 리뉴얼이므로 as-is 조사가 첫 산출물이라는 전제다.

**그 전제의 실물이 어디에도 없다.** 2026-08-31 에 세 곳을 확인했다.

| 찾은 곳 | 결과 |
|---|---|
| Figma `Archive` 페이지 | **빈 페이지.** `<canvas name="Archive" />` 로 자식이 0개다 |
| 반입 번들 `ui_kits/mentree-app-legacy` | **2.0 데모다.** 새 디자인 시스템(`MentreeDesignSystem_0030ae`)을 쓰고 화면에 「이 킷에서는 홈과 멘토 찾기를 데모합니다」라고 적혀 있다 |
| Claude Design 재개 팩 | 「기존 구현을 함께 반영」이라고 쓰지만 실물의 위치를 적지 않았다 |

## 결정

**as-is 조사를 하지 않는다.** `screen-inventory` 의 「유래」 열을 없애고 3분류를 걷어낸다.

## 근거

- **새 와이어가 이미 전부 있다.** Figma `Wireframe` 페이지가 24덩어리 5MB 이고 온보딩·멘토 찾기·멘토링 신청·마이페이지·Q&A·알림·아티클을 덮는다. 만들 대상은 여기서 나온다.
- **3분류의 산출물이 쓰이는 곳이 「유래」 열 하나뿐이다.** UI-SPEC·`DS-nn`·토큰·`UX-PATTERNS` 어디에도 걸리지 않는다.
- **데이터 이관은 BE 소관이고 별 리포다.** 옛 구현을 참조하는 것은 BE 쪽이며 이 리포의 규약을 따르지 않아도 된다(`CLAUDE.md` 역할표).
- **전 행이 같은 값이 되는 열은 정보가 아니다.** as-is 가 없으면 전부 `신규` 가 되므로 열을 남길 이유가 없다.
- 채택하지 않은 안: **1.0 을 별도로 조사한다.** 실물을 새로 확보해야 하고, 위 3개 이유로 FE 디자인이 그 결과를 쓰지 않는다.

## 귀결

- **폐지 화면이 보이지 않는다.** 1.0 에 있고 2.0 와이어에 대응이 없는 화면은 조용히 사라진다. 새 와이어의 완전성은 아직 검증되지 않았다.
- 부분 안전망은 **BE 다.** 옛 엔드포인트를 훑는 과정에서 소비자 없는 API 가 드러난다.
- 되돌리려면 `screen-inventory` 에 열을 다시 만들고 `docs/SOURCES.md` 의 출처 정의를 되돌려야 한다. 이미 목록화한 행에는 유래를 소급 기입해야 한다.
- 나중에 화면의 출처(와이어에 있었는가 / 작업 중 추가했는가)를 구분해야 해지면 그때 열을 더한다. 지금 만들지 않는다.
