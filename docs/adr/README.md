# ADR — 아키텍처 결정 기록

되돌리기 어려운 결정만 남긴다. **결정의 수를 늘리는 것이 목적이 아니다.**

## 무엇을 ADR 로 남기는가

| 판정 조건 | 아크션 |
|---|---|
| 되돌리려면 코드·문서를 여러 곳 고쳐야 한다 | **ADR 로 남긴다** |
| 나중에 「왜 이렇게 했지」가 반드시 나온다 | **ADR 로 남긴다** |
| 디자인 규칙이다 | ADR 이 아니다. [DESIGN.md](../../design/DESIGN.md) 또는 `P-nn` |
| 디자인 시스템의 구현 요구다 | ADR 이 아니다. [DS-update-list.md](../../design/DS-update-list.md) 의 `DS-nn` |
| 그 자리에서 정할 수 있고 되돌리기 쉽다 | **남기지 않는다.** 정하고 진행한다 |

## 파일 이름

`NNNN-slug.md` (`0001-` 부터 순번). 번호는 재사용하지 않는다.
