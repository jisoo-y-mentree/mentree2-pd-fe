# ADR-0001: SSoT는 실장 리포다. Claude Design은 작업·검증 환경이다

- 상태: 승인
- 날짜: 2026-08-31

## 문맥

디자인 시스템을 Claude Design에서 만들고 있다. 산출물은 토큰 파일(`tokens/*.css`)과 컴포넌트 소스(표준 React `.jsx`)다. 구현은 리포에서 일어난다.

어느 쪽이 정본인지 정하지 않으면 양쪽에서 고치게 된다. 어긋난 것을 아무도 발견하지 못한다.

## 결정

**SSoT는 실장 리포다.** Claude Design은 작업·검증 환경이다.

컷오버 시점은 **repo 적재**(Claude Design 재개작업 6번)다. 그때까지는 Claude Design이 SSoT다.

예외가 하나 있다. **이름은 컷오버 전부터 용어집이 정본이다.** 컴포넌트 고아 분석에서 새 이름이 다수 나오므로, 이름을 짓기 전에 용어집에 행을 추가한다.

## 근거

- 토큰이 CSS 변수이고 컴포넌트가 표준 React이며 외부 의존성이 0이다. 리포로 무손실 이관된다. 정본을 리포에 두면 값이 코드로 관리되고 diff가 남는다.
- Claude Design은 장애로 산출물이 깨진 적이 있다. 작업본을 정본으로 두면 복구 수단이 없다.
- 채택하지 않은 안: **Claude Design을 계속 정본으로 둔다.** 구현이 리포에서 일어나므로 정본과 구현이 갈린다. 리포의 값을 고쳐야 하는 상황에서 정본을 고칠 수 없다.

## 귀결

- 컷오버 이후 Claude Design에서 값을 고쳐도 리포에 반영되지 않는다. 고칠 곳은 리포다.
- 컷오버 전에는 리포의 `DESIGN.md`와 `packages/design-system`이 비어 있는 것이 정상이다.
- 되돌리려면 토큰·컴포넌트·문서의 참조를 전부 되돌려야 한다.
- 관련: [ADR-0003](0003-design-system-package-placement.md), `docs/SOURCES.md` 「컷오버」 절
