# 화면 인벤토리

> mentree 리뉴얼의 화면 목록과 진행 상태다. **어느 화면부터 만들지**를 여기서 정한다.

## 현행 조사 (as-is)

**리뉴얼이므로 「지금 무엇이 있고 무엇을 버리는가」가 첫 산출물이다.** 스크래치 개발과 다른 점이다.

| 판정 조건 | 아크션 |
|---|---|
| 현행에 있고 남긴다 | 아래 표에 `계승` 으로 넣는다 |
| 현행에 있고 버린다 | 아래 표에 `폐지` 로 넣고 이유를 쓴다 |
| 현행에 없고 새로 만든다 | 아래 표에 `신규` 로 넣는다 |

**조사 없이 화면을 만들기 시작하지 않는다.** 현행 사용자가 쓰던 흐름을 모르고 만들면 리뉴얼이 아니라 별개 제품이 된다.

## 만드는 순서

| 판정 조건 | 아크션 |
|---|---|
| 첫 화면을 고른다 | **파이프라인을 실증할 수 있는 작은 화면**을 고른다. 제일 중요한 화면을 고르지 않는다 |
| 디자인 시스템이 아직 얇다 | 부품을 적게 쓰는 화면부터 만든다. `DS-nn` 이 한꺼번에 쏟아지지 않게 한다 |
| 화면끼리 의존한다 | 전이의 출발점이 되는 화면을 먼저 만든다 |
