# TagInput

태그를 넣고 빼는 폼 필드. `qna-compose`의 본체다.

**`Chip`을 대체하지 않는다. `Chip`을 담는다.** 화면에 보이는 태그는 전부 `Chip md`다.

## 구조

- **바깥 상자**는 `Input`의 테두리·radius·포커스 링을 그대로 쓴다(새 값 없음). 안쪽 어디에 포커스가
  있어도(칩의 ✕, 텍스트 입력) 링은 상자에 그린다.
- **입력 줄**: 확정된 `Chip md`들이 먼저 서고, 그 뒤에 텍스트 입력이 남은 폭을 채운다. 줄이 넘치면 아래로
  감싼다. 텍스트 입력 자체에는 테두리·배경이 없다 — 상자가 이미 필드다.
- **＋ 버튼**: 입력 줄 오른쪽 끝, `IconButton ghost sm`. 지금 친 글자를 확정한다. 비어 있으면 disabled.
- **제안 줄**: 구분선 아래, 상자 안쪽(바깥에 뜨는 드롭다운이 아니다). 라벨 + `Chip md` 가로 나열.
- **카운터**: 상자 바깥 오른쪽 아래에 `0/10`.

## 제안 줄은 하나뿐이고 갈아끼운다

쌓지 않는다 — 쌓으면 칠 때마다 상자 높이가 흔들린다.

| 조건 | 라벨 | 내용 |
|---|---|---|
| 입력 비어있음/1글자 | 추천 태그 | `suggestions` 최대 5건 |
| 입력 2글자 이상 | 이런 태그가 있어요 | `completions` 최대 3건 |
| 자동완성 0건 | 이런 태그가 있어요 | `+ "<친 글자>" 추가` 칩 1개(자유입력 허용) |
| 10개 찼음 | — | 제안 줄 전체 숨김 |

제안 칩은 `Chip md` + `onClick`(Chip의 onClick 경로). 누르면 입력 줄로 올라가고 제안 줄에서 사라진다.
이미 넣은 태그는 제안에 안 나온다.

**정렬·필터·2글자 판정은 부품이 하지 않는다** — 바깥이 정렬해 넘긴 배열을 순서 그대로 세운다. 부품은
①자르기 ②이미 넣은 것 빼기 ③어느 목록을 보일지 고르기만 한다. 추천 기준(사용 횟수 → 클릭률 → 최근
답변 → 국가 확대)은 서버가 정한다.

## 색

`Chip` 기본값 `--muted`를 그대로 쓴다. 제안 칩도 입력된 칩도 같은 색 — 자리와 ✕ 유무로만 가른다.
같은 "태그" 데이터가 화면마다 색이 다르면 안 된다(Q&A 카드의 해시태그도 `--muted`).

## 키보드

| 키 | 동작 |
|---|---|
| Enter | 확정(`preventDefault`로 폼 제출 막음). 하이라이트된 제안이 있으면 그것을 확정 |
| 쉼표·스페이스 | 확정 |
| Backspace(입력 비어있음) | 마지막 칩 삭제 |
| ESC | 제안 줄만 접는다. 입력 내용은 남긴다 |
| ↑↓ | 제안 칩 훑기. Enter로 확정 |
| (조합 중) | 아무 키도 가로채지 않는다 — IME 조합을 끊지 않는다 |

확정 시 앞뒤 공백을 떼고 앞의 `#`을 뗀다 — `#`을 쳐도 데이터에는 안 들어간다(`Chip`의 `prefix="#"`가
표시만 맡는다). 이미 있는 값이면 넣지 않고 입력만 비운다(에러 없음). 빈 문자열·공백뿐이면 아무것도
안 한다.

## 10개가 차면

텍스트 입력과 ＋를 비활성한다(지우면 돌아옴). 제안 줄을 숨긴다. 카운터 `10/10`을 `--primary`로 —
**빨강을 쓰지 않는다**, 에러가 아니라 한계다.

## 상태

`default · focus · disabled · invalid · 가득참`. disabled면 상자·칩·입력 전부 흐려지고 칩의 ✕도
사라진다(onRemove를 넘기지 않아 Chip이 표시 전용으로 렌더된다).

## 접근성

상자에 `role="group"`, 텍스트 입력에 `aria-label`. 제안 줄에 `aria-live="polite"`. 카운터를
`aria-describedby`로 입력에 잇는다. ✕ 버튼 접근명은 `"<태그명> 삭제"`(Chip의 `removeAriaLabel`).
가득참은 색이 아니라 비활성과 문구로 전달된다.

## 어디에 쓰나

`qna-compose` 1화면. `Field` 안에 넣어 라벨 「태그」와 설명을 붙인다.

```jsx
<Field label="태그" description="최대 10개까지 태그 설정이 가능합니다">
  <TagInput value={tags} onChange={setTags} suggestions={recommended} completions={matched} />
</Field>
```

## 만들지 않는 것

바깥에 뜨는 드롭다운 · size 2종(1종만) · 칩의 새 색·새 모양 · 태그 정렬·중복 검색 로직(바깥의 일).
