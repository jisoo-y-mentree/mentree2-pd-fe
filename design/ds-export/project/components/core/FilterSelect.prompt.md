# FilterSelect

조건 축의 **트리거와 그 모달 한 벌**이다. 앞판은 `Popover`로 만들었으나 국가만 19개고 직종·키워드는
더 많아 앵커 팝오버(기본 `minWidth` 168)에 안 들어간다. **`Dialog`로 간다.**

## 새로 만드는 것은 트리거와 조립뿐이다
- **Dialog**(overlays) — 모달 껍데기. `title`·`footer`·`width`.
- **FilterChip**(core) — 모달 안의 선택지. 국가 축은 `leading="flag"`.
- **Chip**(core) — 하단 바의 선택 요약. `md` + `onRemove`.
- **Button**(core) — "초기화" `outline`·"N개 적용하기" `primary`.

`Popover`를 쓰지 않는다. `Tabs`를 쓰지 않는다(아래).

## 트리거
```
[ 국가  ⌄ ]            0개 — 축 이름만
[ 일본  ⌄ ]            1개 — 값
[ 일본 외 2  ⌄ ]       2개 이상 — 첫 값 + "외 N"
```
- 기하는 Button sm과 같다(높이 32·radius-md·caption/500). pill 아니다.
- 선택 0개: 면 투명·1px `--border`·라벨 `--muted-foreground`.
- 선택 1개 이상: 면 `--muted`·1px `--sage-400`·라벨 `--foreground` 600. 채워지고 테두리가 진해진다.
  **green 반전은 하지 않는다** — 반전은 FilterChip의 것이고, 트리거가 반전하면 모달 안의 칩과 같은 위계로 읽힌다.
- trailing은 `Icon name="arrow-down-01" size={14}`. 모달이 열려 있으면 180° 돈다.
- 국기를 트리거에 넣지 않는다 — 2개 이상이면 어느 국기를 넣을지 정할 수 없다.

## 모달
본문은 **그룹으로 나눈다.** 그룹 제목은 `--text-body`·600·`--foreground`, 위 여백 20·아래 10.
칩은 `FilterChip`을 감싸 세운다(`flexWrap`, gap 8). 그룹이 하나뿐이면 제목을 세우지 않는다.
본문이 모달 높이를 넘으면 본문만 스크롤한다 — `title`과 하단 고정 바는 안 움직인다.

**하단 고정 바**는 `Dialog`의 `footer`에 2줄을 넣는다(`footer`는 우측 정렬이라 `width:"100%"` div로 감싸 배치):
1. 선택 요약 — `Chip md` + `onRemove`. 누르면 그 값만 뺀다. **0개면 이 줄째로 감춘다.**
2. 왼쪽 "초기화"(`Button outline md`) / 오른쪽 "N개 적용하기"(`Button primary md`·`flex:1`).
   선택이 0개면 적용 버튼의 라벨은 "적용"이고 **비활성하지 않는다** — 전부 푸는 것도 조작이다.

두 줄 사이에 구분선을 두지 않는다. 여백으로 가른다.

## 탭을 만들지 않는다
참조 화면엔 상단 탭이 있으나 여기서는 안 만든다. `Tabs`의 사양은 "같은 셸 안에서 내용 자체가 바뀐다"이고
`TabPanel`과 짝이다 — 여기 필요한 건 한 스크롤 안에서 자리로 점프하는 앵커라 그 계약과 어긋난다.
지금은 그룹이 3개다. 목록이 커져 스크롤이 길어지면 그때 별도로 기표한다 — 모르는 것에 맞춰 미리 만들지 않는다.

## 거동 — 즉시 반영하지 않는다
| 판정 조건 | 액션 |
|---|---|
| 트리거를 눌렀다 | 모달을 연다. 지금 걸린 값을 초기 상태로 넣는다 |
| 모달 안에서 칩을 골랐다 | 모달 안에만 반영한다. 바깥 목록을 갱신하지 않는다 |
| "N개 적용하기"를 눌렀다 | `onChange`를 부르고 모달을 닫는다 |
| "초기화"를 눌렀다 | 모달 안의 선택을 비운다. 모달은 열린 채로 둔다. `onChange`를 부르지 않는다 |
| ✕·ESC·바깥 클릭으로 닫았다 | 고른 것을 버린다. 열기 전 상태로 되돌린다 |
| 하단 요약 칩의 ✕를 눌렀다 | 그 값만 뺀다. 모달 안의 해당 칩도 꺼진다 |

즉시 반영하지 않는 이유: 모달이 뒤 목록을 가린 채 매번 재조회하면 고르는 동안 무엇이 바뀌는지 안 보이고
요청만 늘어난다.

## 키보드·접근성
- Enter·Space(트리거): 연다. ESC: 고른 것을 버리고 닫는다. 트리거로 포커스를 되돌린다.
- Tab: 모달 안을 돈다 — `Dialog`의 포커스 트랩을 그대로 쓴다.
- 트리거는 `<button>` + `aria-expanded` + `aria-haspopup="dialog"`.
- 접근명에 개수를 넣는다 — "국가, 3개 선택됨". "외 2"만으로는 스크린리더가 몇 개인지 못 읽는다.
- 그룹은 `role="group"` + `aria-label`에 그룹 제목.

## 어디에 쓰나
`mentor-search`의 조건 줄 — 국가·직종·키워드 3개가 나란히 선다.

```jsx
<FilterSelect
  label="국가"
  groups={[
    { label: "아시아 · 중동", options: asia },
    { label: "유럽", options: europe },
    { label: "북미 · 오세아니아", options: americas },
  ]}
  value={picked}
  onChange={setPicked}
/>
```

## 만들지 않는 것
- 팝오버 형태 — 앞판을 버린다.
- 탭 — 위 참조.
- 모달 안의 검색창 — 그룹으로 나누면 찾을 수 있다. 목록이 더 커지면 그때 기표한다.
- 단일 선택 모드 — 세 축 다 다중이다.
- size 2종·width 2종 — `Dialog width=600` 하나다.
