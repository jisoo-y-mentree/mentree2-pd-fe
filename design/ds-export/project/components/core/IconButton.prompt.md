**IconButton** — 툴바·헤더·테이블 행 액션용 정사각 아이콘 전용 버튼.

```jsx
<IconButton icon="search-01" ariaLabel="검색" />
<IconButton icon="more-horizontal-circle-01" variant="ghost" />
```

variant `primary | secondary | outline | ghost`(ghost가 기본, 호버 시 sage로 채워짐). 크기 `sm | md | lg` = 32/38/44px. `ariaLabel`은 항상 전달.
