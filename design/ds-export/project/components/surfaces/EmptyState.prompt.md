# EmptyState

목록이 **0건일 때 그 자리에 서는 것**. 자리를 비워두지 않는다.
쓰는 곳: 멘토 찾기(검색 0건) · Q&A 피드(검색 0건 / 우측 위젯의 내 질문 0건) · 알림(새 알림 0건) · 마이페이지 각 탭.

## 두 종류를 하나로 담는다

빈 상태는 원인이 둘이고 낼 말이 다르다.

1. **아직 없다** — "아직 질문이 없으시네요!" → 다음 행동으로 보낸다(질문하기 버튼).
2. **찾았는데 없다** — "찾으시는 질문이 없습니다" → 조건을 풀거나 새로 만들게 한다.

**prop으로 가르지 않는다.** 아이콘·제목·설명·액션을 슬롯으로 받고, 어느 쪽인지는 **화면이 문구로 정한다**.
빈 상태의 종류를 부품이 알 필요가 없다.

## 문구를 부품에 넣지 않는다

**기본 문구를 하드코딩하지 않는다.** 한/일 2개국어이고 문구는 아직 정해지지 않았다 — 전부 화면이 넘긴다.

## 구성

위에서 아래로 4단, 전부 가운데 정렬.

1. **아이콘** — HugeIcons. 선택.
2. **제목** — 한 줄. 필수.
3. **설명** — 한두 줄. 선택.
4. **액션** — Button. **0개나 1개.** 2개 이상 두지 않는다 — 빈 화면에서 고민을 시키지 않는다
   (배열이 들어와도 첫 하나만 선다).

## 크기 2종

- **md** — 목록 자리 전체를 채운다. 멘토 찾기·Q&A 피드의 본문. 아이콘 34, 상하 여백 44.
- **sm** — 좁은 자리. Q&A 피드의 우측 위젯·알림 드롭다운. 아이콘 22, 상하 여백 22, 설명은 생략해도 된다.

## 시각

- **배경 없음 · 테두리 없음** — 카드 셸을 상속하지 않는다.
- 제목 `--foreground` · 설명 `--muted-foreground` · 아이콘 `--muted-foreground`. **채도를 쓰지 않는다.**
- **일러스트를 그려 넣지 않는다** — 화면마다 달라진다.

빈 상태가 눈에 띄면 안 된다. 없다는 사실을 알리고 다음으로 보내는 것이 일이다.

```jsx
<EmptyState
  icon="message-question"
  title="아직 질문이 없으시네요!"
  description="궁금한 점을 남기면 멘토가 답해 드립니다."
  action={<Button size="sm">질문하기</Button>}
/>

<EmptyState size="sm" icon="notification-01" title="새 알림이 없습니다" />
```
