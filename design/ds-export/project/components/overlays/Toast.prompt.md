# Toast

> 구현은 sonner(2.0.8 · MIT · 런타임 의존 react·react-dom)를 쓴다.
> 이 파일은 그 위에 얹을 우리 쪽 규칙이다 — 토큰·체류 시간·액션 수·정지 조건.
> .jsx는 시각과 거동의 참조이지 이식원이 아니다.

## sonner를 여기서 import하지 않는 이유

ds-export는 외부 의존성이 0이고, 그게 엔지니어 인계의 조건이다. 이 `.jsx`는 표준 React로 모양·거동만
낸 참조 구현이다 — 실장에서는 sonner 위에 이 파일의 규칙(체류 시간·액션 수·정지 조건·형태)을 얹는다.

## 무엇인가

화면 위에 잠깐 떴다 사라지는 알림. 와이어에 3가지가 있다.

| | 화면 | 문구 | 액션 |
|---|---|---|---|
| A | mentor-search 스크랩 | "스크랩했습니다" | 실행취소 1개 |
| B | article-detail 공유 대체 | "링크를 복사했습니다" | 0개 |
| C | qna-feed 스크랩 | "답변이 달리면 알람을 받을까요?" | 받기/괜찮아요 2개 |

**variant를 만들지 않는다** — 셋의 차이는 액션의 수뿐이다. `actions` 배열의 길이가 곧 종류를 정한다.

## 체류 시간 — 액션 수가 정한다

- 액션 0~1개 → **3000ms**(와이어 "토스트 노출 시간 3초" 명시).
- 액션 2개 → **6000ms** — 읽는 양이 배이기 때문. "스크랩했습니다 [실행취소]"와 "답변이 달리면 알람을
  받을까요? [받기][괜찮아요]"는 읽고 이해하고 고르는 데 걸리는 시간이 다르다.

**초 값은 토큰으로 만들지 않는다** — 색·치수가 아니라 거동이라 이 컴포넌트가 상수로 갖는다.

## 사라지지 않아야 할 때

- hover하면 타이머가 멈춘다.
- 포커스가 들어오면 멈춘다.
- 벗어나면 **남은 시간부터** 다시 흐른다(리셋 아님).

실행취소가 있는 토스트에서 이게 없으면 3초 안에 마우스를 올려도 못 누른다. sonner·Material·Radix가
전부 이렇게 한다.

## C의 기본값 — 화면 책임

와이어의 지시: "응답이 없다면 기본 x로." 시간이 지나 사라지면 "안 받음"으로 확정된다. 물어놓고
타임아웃으로 기본값이 정해지는 쓰임이므로, 놓쳐도 손해가 없게 기본이 **"안 받음"**이어야 한다.

**컴포넌트는 기본값을 정하지 않는다** — 화면이 `onDismiss`에서 "안 받음"으로 확정한다. 여기 남기는
사실은 하나, **"타임아웃이 곧 선택이 되는 쓰임이 있다"**는 것뿐이다.

## 형태

- 면 `--card` · 1px `--border` · `--radius-md` · `--shadow-md`.
- 문구는 `--text-body`. 액션은 텍스트 버튼(Button ghost sm 레시피).
- **파괴적 액션은 없다.** 실행취소류는 `--primary`(emphasis="primary"), 그 외 기본은 `--foreground`.
- **아이콘을 넣지 않는다** — 와이어에 없다.

## 여러 개가 겹칠 때 — 실장(sonner)의 일

이 컴포넌트는 단일 토스트 1개만 낸다. 아래는 실장이 지킬 규칙(참조용, 이 `.jsx`는 구현하지 않는다):

- 쌓는다. 새 것이 위로 온다.
- 동시에 보이는 것은 최대 3개. 넘으면 가장 오래된 것부터 사라진다.
- 같은 내용이 연달아 오면 새로 쌓지 않고 기존 것의 타이머만 되돌린다(스크랩을 빠르게 두 번 누르는 경우).

## 위치

화면 하단. **PC는 우측 하단, 모바일은 가운데 아래.** 모바일에서 BottomTabBar(56px)를 가리지 않게
그 위로 띄운다. 컴포넌트가 `position:fixed`로 직접 앉는다(화면이 배치하지 않는다).

## 상태

`entering · visible · hovered(타이머 정지) · leaving`

## 제어형

`open` + `onDismiss` 제어형 — 토스트를 여는 쪽이 상태를 갖는다. `message` · `actions` 배열을 받는다.
큐 관리는 실장(sonner)의 일이므로 여기서 만들지 않는다.

```jsx
// A — 스크랩 + 실행취소(3s)
<Toast open={open} message="스크랩했습니다" actions={[{ label: "실행취소", emphasis: "primary", onClick: undoScrap }]} onDismiss={() => setOpen(false)} />

// B — 공유 대체 안내(3s, 액션 없음)
<Toast open={open} message="링크를 복사했습니다" onDismiss={() => setOpen(false)} />

// C — 양자택일 질문(6s). 타임아웃 시 화면이 "안 받음"으로 확정.
<Toast open={open} message="답변이 달리면 알람을 받을까요?"
  actions={[{ label: "받기", onClick: () => confirm(true) }, { label: "괜찮아요", onClick: () => confirm(false) }]}
  onDismiss={() => { confirmDefault(false); setOpen(false); }} />
```
