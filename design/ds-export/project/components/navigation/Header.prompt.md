**Header** — 제품 기본 상단 네비게이션(**sticky top**). 좌우 3분할: 좌(로고) / 중(메뉴) / 우(액션). 이 제품은 사이드바를 쓰지 않는다(`Sidebar`는 참조·레거시). 푸터는 `Footer`.

```jsx
<Header
  activeKey="mentors"
  authState="guest"
  onNavigate={(item) => go(item)}
  onAuth={() => openAuth()}
/>
```

- **좌 — 로고**: mentree 워드마크 **풀컬러 그린**(헤더는 밝은 배경 → 풀컬러 유지, 푸터 다운과 별개). 클릭 → 홈.
- **중 — 최상위 메뉴 3개**: 멘토 찾기 · Q&A 멘토링 · 멘트리 인사이트(biz 제외). 각 메뉴 좌측 **20px HugeIcons 모노 아이콘**(전역 아이콘 원칙의 예외 아님 — BottomTabBar와 동일 이름). 라벨 **16px·600**, **활성은 색(`--primary`)으로만 구분**(굵기 동일).
- **우 — 액션(비로그인)**: **회원가입/로그인**을 green 버튼 **하나로 합침**(분리 안 함) + **기업 서비스**(중립 outline 버튼 — 테두리·텍스트 모두 중립 시맨틱 토큰, 외부 ↗·파랑 없음). 공지사항·뉴스는 헤더에 **두지 않음**(푸터에만).
- **우 — 액션(로그인 mentor·mentee)**: **알림 버튼** + **아바타**, 간격 8, 컨테이너 우측 끝. **평상시엔 면이 없다** — 알림은 아이콘 **20**만, 아바타는 사진 **32**만 보인다. **hover·focus에서만 40 원형 면**(`--secondary`)이 깔린다. 클릭·터치 영역은 **항상 40×40**이고 보이는 것만 달라진다. 아이콘 색은 `--foreground`(muted는 너무 흐리다). 회원가입·기업서비스 **없음**. 두 상태는 모양이 같고 **아바타 목적지만 다르다**(mentor→`mypage-mentor`, mentee→`mypage-mentee`). 아바타는 메뉴를 열지 않고 마이페이지 「프로필」 탭으로 직행. `unread`면 빨간 점(지름 8 + `--background` 링 2, 숫자 없음) — **붙는 곳은 20 아이콘의 우상단**(`top -1 / right -1`, 외접원 45°)이고 40 hover 면이 아니다. 면은 평상시 안 보이므로 거기 맞추면 점이 허공에 뜬다. 아바타에는 점을 붙이지 않는다. 알림 popover는 이 부품이 열지 않음(`onNotify`까지).
- **그리드**: `minmax(0, 1fr) auto minmax(0, 1fr)` — 좌우를 그냥 `1fr`로 두면 내용의 최소 폭 아래로 줄지 않아 좁은 데스크톱(769–1279)에서 중앙 메뉴가 화면 중앙에서 밀린다. **칸은 `grid-column`으로 명시한다**(로고 1 · 메뉴 2 · 액션 3) — `display:none`인 요소는 그리드 아이템이 아니게 되어 자동 배치가 한 칸 당기고, 액션부가 2번 칸으로 밀려 우측에 빈 칸이 남는다. **1280에서 중앙 메뉴 중심이 x = 640인 것은 이 변경으로 깨지지 않는다.**
- **Mobile(~768)**: 중앙 3메뉴 제거, 우측 = 액션부 + 햄버거(48). 칸을 **2개**(`minmax(0,1fr) auto`)로 줄이고 `gap`을 **12**로, 액션부를 `grid-column: 2`로 옮긴다 — 중앙 칸이 0 폭이어도 `gap` 24가 두 번 들어가 48이 그냥 버려진다. 액션부 오른쪽 끝이 **374**(= 390 − 16)에 선다.
- **오버레이 메뉴 정렬**: 감싸는 `nav`의 좌우 패딩은 `calc(var(--container-pad) - 8px)` — 항목의 `padding: 0 8px`는 hover 면을 넓히는 값이라 그대로 두고, 그만큼을 바깥에서 뺀다. 글자와 아이콘이 **헤더 로고와 같은 x = 16**에 서고 hover 면은 여전히 넓다.
- **상태 분기**: `authState` guest(비로그인) / mentor / mentee.
