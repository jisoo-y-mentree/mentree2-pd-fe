# 03 · 리스폰시브 지침

> TOP 및 모든 화면의 반응형 기준. 데스크톱 우선 설계 → 축소 대응.
> Tailwind 기본 브레이크포인트 사용, mentree 운용 구간은 아래 3구간.

---

## 브레이크포인트 (3구간)

| 구간 | 폭 | 핵심 차이 |
|---|---|---|
| **Desktop L** | 1280+ | 컨테이너 1280. 헤더 풀메뉴(기업 서비스 버튼 포함). |
| **Desktop S** | 769–1279 | 헤더에서 **기업 서비스 버튼만 숨김**. 텍스트 3메뉴 + 회원가입/로그인 유지. |
| **Mobile** | ~768 | 헤더 축약(로고+회원가입/로그인+햄버거) + 하단 탭바. |

- Desktop L/S는 본문 레이아웃 대체로 공유, 헤더만 다름. Mobile에서 구조 크게 전환.
- 컨테이너 좌우 패딩: Desktop 24 → Mobile 16.

## 헤더

- **Desktop L**: 로고 / 3메뉴 / 회원가입·로그인 + 기업 서비스(중립 outline).
- **Desktop S**: 위와 동일, 기업 서비스 버튼만 숨김(푸터·햄버거에 있음).
- **Mobile**: 로고 / 회원가입·로그인 + 햄버거 · 하단 탭바.
- **햄버거 = 전체화면 오버레이**: GNB 바 유지(로고·회원가입로그인 계속 보임), 햄버거↔X 토글.
  좌측 정렬 세로 리스트, 항목 큼직하게:
  ```
  멘토 찾기 / Q&A 멘토링 / 멘트리 인사이트 / MY 멘트리   (28px 컬러 SVG, MY는 placeholder)
  ──────────── (구분선, 상시)
  기업 서비스 ↗   (biz 파랑, 상시)
  로그아웃         (HugeIcons 모노, 로그인 시만)
  ```

## 하단 탭바 (Mobile 전용)

- 4탭: 멘토 찾기(user-search-01) · Q&A 멘토링(quiz-05) · 멘트리 인사이트(news) · MY 멘트리(user-circle-02).
- HugeIcons 모노, 높이 56, frosted glass(white 반투명+blur), iOS safe-area, 활성 green.
- MY 멘트리: 비로그인 시 로그인 유도(자리만).
- **헤더·탭바 = 상하 내비 짝, 같은 frosted glass 표면 언어.**

## 캐러셀

| 구간 | 거동 |
|---|---|
| Desktop L/S | 가로 캐러셀. peek(멘토)/snap-fit(그 외). 화살표(SectionHeader) + overflow 시 페이드. |
| Mobile | 가로 스크롤 유지. **화살표 숨김**(스와이프), **페이드 없음**. 세로스택·더보기 없음. |

## 타입스케일 (반응형)

| 토큰 | Desktop | Mobile |
|---|---|---|
| display (히어로 제목) | 40 | 24 |
| h0 (섹션 제목) | 30 | 20 |
| h1 24 / h2 20 / h3 16 / body 14 / caption 12 | | (h1↓ 미세조정은 실전) |

- display/h0에 미디어쿼리로 모바일 값 적용(토큰이라 일괄).

## 히어로 (정식 설계 — 단, 지구본 미해결로 보류 중)

- **Desktop(L/S)**: 좌우 2단. 좌 카피(display 40, "해외 커리어" green)+서브(20, "141명" green)+진입아이콘 / 우 지구본.
- **Mobile**: 지구본이 우측 자리 → 뒤 배경으로(우상단, 일부만). 그 위 카피·아이콘 세로.
  - 전환: 폭 감소에 따라 지구본이 우측→우상단으로 연속 이동(clamp/vw). 텍스트는 항상 좌측.
  - 목표 스냅샷 3폭: 1280 / 767 / 390.
- **진입 아이콘 4개**: 라벨 = 1:1 멘토링 신청 · 무엇이든 질문 · 필독 컨텐츠 · 이벤트.
  - **카드 제거**(이모지→컬러 SVG 예정, 배경/테두리 없음).
  - Desktop: fill 아님 — 개당 폭 110, 간격 12, 좌측 정렬. Mobile: fill 균등, 텍스트 13/아이콘 40.
- ⚠️ **지구본이 "우측에서 잘린 일부 + 아시아 마커"로 안 나오는 문제 미해결 → 히어로 보류.** (06 참조)

## 본문 섹션 Mobile 전환

- **MentorCard**: 고정폭 296 유지, 미디어 5:4, 국가 배지 국기만(labelHidden), 소개 2줄.
- **InterviewCard**: 모바일 세로형 **미구현**(인터뷰 섹션 재작업 시 — 보류).
- **필터칩**: 가로 스크롤.
- **Biz CTA**: 좌우 2단 → 세로. **버튼 1개**("자세히 알아보기" primary biz, 문의하기 폐기).
- 탭바 적용 시 본문 하단 패딩 56+safe-area(푸터 안 가리게).

## 컨테이너

- `--container-max` 1280 / `--container-pad` 24→16(Mobile). 배경 풀블리드, 콘텐츠만 1280 정렬.
  Header·본문·Footer 공통 참조(좌우 끝선 일치).
