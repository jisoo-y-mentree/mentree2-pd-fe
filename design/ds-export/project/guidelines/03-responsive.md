# 03 · 리스폰시브 지침

> TOP 및 모든 화면의 반응형 기준. 데스크톱 우선 설계 → 축소 대응.
> Tailwind 기본 브레이크포인트 사용, mentree 운용 구간은 아래 3구간.

---

## 브레이크포인트 (3구간)

| 구간 | 폭 | 핵심 차이 |
|---|---|---|
| **Desktop L** | 1280+ | 컨테이너 1280. 헤더 풀메뉴(기업 서비스 버튼 포함). |
| **Desktop S** | 769–1279 | 헤더에서 **기업 서비스 버튼만 숨김**. 텍스트 3메뉴 + 회원가입/로그인 유지. |
| **Mobile** | ~768 | 헤더 축약(로고+회원가입/로그인+햄버거) + 하단 탭바. |

- Desktop L/S는 본문 레이아웃 대체로 공유, 헤더만 다름. Mobile에서 구조 크게 전환.
- 컨테이너 좌우 패딩: Desktop 24 → Mobile 16.

## 헤더

- **Desktop L**: 로고 / 3메뉴 / 회원가입·로그인 + 기업 서비스(중립 outline).
- **Desktop S**: 위와 동일, 기업 서비스 버튼만 숨김(푸터·햄버거에 있음).
- **Mobile**: 로고 / 회원가입·로그인 + 햄버거 · 하단 탭바.
- **햄버거 = 전체화면 오버레이**: GNB 바 유지(로고·회원가입로그인 계속 보임), 햄버거↔X 토글.
  좌측 정렬 세로 리스트, 항목 큼직하게:
  ```
  멘토 찾기 / Q&A 멘토링 / 멘트리 인사이트 / MY 멘트리   (28px 컬러 SVG, MY는 placeholder)
  ──────────── (구분선, 상시)
  기업 서비스 ↗   (biz 파랑, 상시)
  로그아웃         (HugeIcons 모노, 로그인 시만)
  ```

## 하단 탭바 (Mobile 전용)

- 4탭: 멘토 찾기(user-search-01) · Q&A 멘토링(quiz-05) · 멘트리 인사이트(news) · MY 멘트리(user-circle-02).
- HugeIcons 모노, 높이 56, frosted glass(white 반투명+blur), iOS safe-area, 활성 green.
- MY 멘트리: 비로그인 시 로그인 유도(자리만).
- **헤더·탭바 = 상하 내비 짝, 같은 frosted glass 표면 언어.**

## 캐러셀

| 구간 | 거동 |
|---|---|
| Desktop L/S | 가로 캐러셀. peek(멘토)/snap-fit(그 외). 화살표(SectionHeader) + overflow 시 페이드. |
| Mobile | 가로 스크롤 유지. **화살표 숨김**(스와이프), **페이드 없음**. 세로스택·더보기 없음. |

## 타입스케일 (반응형)

| 토큰 | Desktop | Mobile |
|---|---|---|
| display (히어로 제목) | 32 / lh 40 | 26 / lh 34 |
| h0 (섹션 제목) | 24 / lh 32 | 20 / lh 28 |
| h1 (페이지 안 큰 제목) | 22 / lh 30 | 20 / lh 28 |
| h2 (카드 제목 360px+) | 20 / lh 28 | 20(고정) |
| h3 (카드 제목 280–360px) | 18 / lh 26 | 18(고정) |
| article (읽을거리 본문) | 17 / lh 28 | 17(고정) |
| body (카드 제목~280px 포함) | 16 / lh 24 | 16(고정) |
| caption (카드 안 글·보조) | 14 / lh 20 | 14(고정) |
| micro (배지·탭바 라벨) | 12 / lh 16 | 12(고정) |

- **반응형은 `display`·`h0`·`h1` 세 단에만 건다.** 벤치마크는 모바일에서 거의 안 내린다 — 원티드 홈 최대 제목(섹션 제목이 아니라 페이지 최상단 제목) 22→22 · 상세 본문 16→16 · 보조 13→13 · 배지 11→11(내려가는 것은 상세 주제목 28→20 하나뿐), 토스 아티클 h2 30→30 · 본문 17→17 · 카드 제목 20→20.
  - `h2`·`h3`를 내리지 않는 이유: **카드 제목은 폭 규칙이 이미 처리한다.** 토큰에도 걸면 두 번 내려간다.
  - `article`을 내리지 않는 이유: 토스 본문이 1280에서 17, 390에서도 17이다(글자수 4,651↔4,648).
- 자간은 작을수록 넓히고(micro +0.01em) 클수록 좁힌다(display −0.025em). 줄높이는 배수가 아니라 고정 px(4의 배수) — 반응형 3단은 크기와 함께 줄높이도 낮춰 배율을 Desktop과 맞춘다(그대로 두면 줄 간격이 벌어진다).
- **컨트롤 라벨은 자간 0, 줄높이 1**이다(`Button`·`Chip`·`FilterChip`·`Badge`·`BottomTabBar`·`Tabs`·`ToggleGroup`, 입력 안의 글자도 동일). 그 밖의 텍스트는 토큰의 자간·줄높이를 그대로 쓴다. 근거: 원티드 실측(2026-09-14) — 11px +0.3 / 16px +0.1 / 20px −0.2 / 28px −0.7.
- display/h0/h1에만 미디어쿼리로 모바일 값 적용(토큰이라 일괄).

### 지침 — 카드 제목은 카드 폭이 정한다

**3구간이다.** 폭이 커져도 제목은 거의 안 변한다.

| 카드 폭 | 제목 토큰 |
|---|---|
| ~280 | `--text-body`(16) · 600 |
| 280–360 | `--text-h3`(18) |
| 360+ | `--text-h2`(20) |

근거: **원티드 실측(2026-09-15, @1280): 250→16 · 333→17. 토스: 238→20 · 652→20** — 원티드는 폭 33%가 늘어도 ＋1, 토스는 폭 2.7배인데 고정이다. 그래서 옛 `430+ → h1 24` 구간을 없앴다 — 근거가 없다.
`MentorCard`(296) → `--text-h3` · `InterviewCard`(400) → `--text-h2` · `QnaCard`·`ArticlePreview`(296) → `--text-h3`.
**`MentorCard`만 폭에 따라 토큰이 갈린다** — `fluid`로 폭이 실제로 179까지 줄 때만 모바일에서 `--text-body` 16이다(주입 스타일시트의 `.mt-mcard-fluid .mt-card-link`). `fluid`가 아닌 296 고정 카드는 캐러셀 안이라 폭이 안 줄어들어 모바일에서도 `h3` 18이다.

## 히어로 (정식 설계 — 단, 지구본 미해결로 보류 중)

- **Desktop(L/S)**: 좌우 2단. 좌 카피(display 40, "해외 커리어" green)+서브(20, "141명" green)+진입아이콘 / 우 지구본.
- **Mobile**: 지구본이 우측 자리 → 뒤 배경으로(우상단, 일부만). 그 위 카피·아이콘 세로.
  - 전환: 폭 감소에 따라 지구본이 우측→우상단으로 연속 이동(clamp/vw). 텍스트는 항상 좌측.
  - 목표 스냅샷 3폭: 1280 / 767 / 390.
- **진입 아이콘 4개**: 라벨 = 1:1 멘토링 신청 · 무엇이든 질문 · 필독 컨텐츠 · 이벤트.
  - **카드 제거**(이모지→컬러 SVG 예정, 배경/테두리 없음).
  - Desktop: fill 아님 — 개당 폭 110, 간격 12, 좌측 정렬. Mobile: fill 균등, 텍스트 13/아이콘 40.
- ⚠️ **지구본이 "우측에서 잘린 일부 + 아시아 마커"로 안 나오는 문제 미해결 → 히어로 보류.** (06 참조)

## 본문 섹션 Mobile 전환

- **MentorCard**: 고정폭 296 유지, 미디어 5:4, 국가 배지 국기만(labelHidden), 소개 2줄. 이름은 `--text-h3`(카드 폭 296 = 280–360 구간) — `fluid`로 179까지 줄 때만 `--text-body` 16.
- **InterviewCard**: 모바일 세로형 **미구현**(인터뷰 섹션 재작업 시 — 보류). 카드 폭 400 = 360+ 구간 → 제목 `--text-h2`(모바일에서도 안 바뀐다).
- **필터칩**: 가로 스크롤.
- **Biz CTA**: 좌우 2단 → 세로. **버튼 1개**("자세히 알아보기" primary biz, 문의하기 폐기).
- 탭바 적용 시 본문 하단 패딩 56+safe-area(푸터 안 가리게).
