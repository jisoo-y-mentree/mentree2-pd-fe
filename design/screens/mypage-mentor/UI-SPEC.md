# 1부 — UX 설계 의도 (§1~5) — 멘티와 다른 것

## 1. 화면의 사명

멘티와 같다. **더해지는 물음이 둘이다** — 「받은 신청에 내가 답했는가」(신청받은 멘토링) · 「받은 꽃송이가 얼마이고 정산됐는가」(정산).

## 2. 대상 사용자와 상황

- 대상 사용자: **로그인한 멘토.** 멘토도 다른 멘토에게 신청하므로 **신청한 멘토링** 탭이 따로 있다(2026-09-24 결정)
- 상황: ① 알림 「멘토링 신청이 도착했습니다」 → **신청받은 멘토링** ② 정산 알림 → **정산 수단 / 이력** ③ 아바타 → 멘토 프로필

## 3. 액션 방침

- 주 액션: **받은 신청에 답한다** — 수락(일정 제안) · 사양 · 재조정 · 참가 · 격려 메세지
- 부 액션: 정산 신청 · 계좌 변경 · 최소 금액 · 자동 기부 · 그 밖은 멘티와 같다

**하지 않는 것**에 더해지는 것: **프로필을 여기서 고치지 않는다** — 멘토 프로필은 `mentor-detail` 의 본인 면이 편집한다. 이 탭은 그리로 보낸다.

# 2부 — 구조 (§6~11) — 멘티와 다른 것

## 6. 블록별 규칙

### 세로 메뉴

8항목이 아니라 **7항목 ＋ 로그아웃**이고, 3번째 「나의 1:1 멘토링」이 **▼ 로 접힌다.** 펼치면 하위 2개(신청받은 · 신청한)가 들여쓰기로 선다. 하위가 선택되면 부모도 켜진 면이다.

### 멘토 프로필 탭

본문이 없다. 메뉴를 누르면 **`mentor-detail?me=1`(본인 면)을 새 창**으로 연다. `template/` 는 `role=mentor&tab=profile` 에서 「새 창에서 열립니다」 한 줄 ＋ `Button outline` 「멘토 프로필 열기」 를 낸다(와이어 그대로).

### 나의 Q&A 멘토링

| 블록 | 규칙 |
|---|---|
| 요약 칩 | 「답변한 멘토링 수 **42**」 · 「도움돼요 수 **162**」 — 숫자는 h2 |
| 하위 탭 | 답변한 (4) ／ 작성한 (6) |
| 목록 | `QnaListItem variant="answer"`(답변한) ／ `question`(작성한). 「총 42건의 Q&A 멘토링」 ＋ `Select` 「최신 등록순」. **더보기** 10건 |

### 신청받은 멘토링 — 멘토링 카드의 상태 줄

| 상태 | 문구 | 버튼 |
|---|---|---|
| 수락 대기 | 멘티로부터 멘토링 신청이 도착했습니다. | `outline` **멘토링 수락하기** · 사양하기 |
| 일정 조율중(내가 보냄) | 멘티에게 일정 조율 요청을 보냈습니다. | `secondary` 일정 조정중(비활성) · 멘토링 취소하기 |
| 일정 조율중(멘티가 요청) | 멘티로부터 일정 재조정 요청이 도착했습니다. | `outline` **일정 재조정하기** · 멘토링 취소하기 |
| 확정 | 멘토링이 확정되었습니다. 2026.07.16 15:00 에 멘토링이 진행됩니다. | `primary` **멘토링 참가하기** · 멘토링 취소하기 |
| 완료 | 멘토링이 완료되었습니다. | **멘티에게 메세지 보내기** ／ 보낸 뒤 「메세지 전송 완료」 배지 |
| 취소 | 멘티의 사정에 의해 취소되었습니다. | 멘티에게 메세지 보내기 ／ 보낸 뒤 사라진다 |

「멘토링 수락하기」 → **같은 모달이 수락 화면으로.** 일정 3개(날짜 · 시작 시각 · 30분 단위 · **최소 3일 뒤**)와 멘티에게 보낼 한마디 → 「수락 완료」. 카드가 **일정 조율중(내가 보냄)** 으로 옮겨 간다.

## 8. 표시·활성 제어 — 더해지는 것

| 판정 조건 | 아크션 |
|---|---|
| 「멘토 프로필」을 눌렀다 | `mentor-detail` 본인 면을 **새 창**으로. 본문은 바뀌지 않는다 |
| 수락 대기 신청이 있다 | 메뉴 「신청받은 멘토링」에 **수 배지**(초록) |
| 「멘토링 수락하기」를 눌렀다 | 같은 모달이 **일정 제안** 화면으로. 최소 3일 뒤만 고를 수 있다 |
| 「사양하기」를 눌렀다 | 사유 → 확인 2스텝(취소와 같은 틀). 카드가 완료 탭의 취소 묶음으로 |
| 격려 메세지를 보냈다 | 그 카드와 모달에서 **「멘티에게 메세지 보내기」가 사라진다** |
| 자동 기부를 켰다 | **확인 모달** → 켜짐. 「자동 기부 설정 중」 |
| 자동 기부를 껐다 | 바로 꺼짐 ＋ `Toast` 「실행취소」 |
| 최소 금액을 바꿨다 | 모달 저장 → 값 갱신 ＋ `Toast` |
| 미정산 금액이 0 이다 | 「기부하기」 비활성 |

## 9. 화면 전이

멘티의 그림에 더해지는 간선: `mypage-mentor` →「멘토 프로필」→ `mentor-detail`(본인 · 새 창) ／ 팔로워 카드 → 멘티 프로필 모달 ／ 「기부하기」 → 기부 확인 모달. 수락 → 수락 완료 → 카드 이동은 `transition-map` §3 그대로.
