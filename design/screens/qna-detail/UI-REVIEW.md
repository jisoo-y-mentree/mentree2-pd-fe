## 375px 는 iframe 으로 쟀다

**headless Chrome 은 창 최소 폭이 500px 다.** `--window-size=375` 를 주면 레이아웃은 500 인 채 **스크린샷만 잘려** 가짜 넘침이 된다.

375 폭 `iframe` 을 420 창 안에 넣어 **진짜 375 뷰포트**를 만들어 다시 쟀다. [design-bolt](../../../.claude/skills/design-bolt/SKILL.md) 가 경고한 함정이다.

## 접근성 — 사람이 판정하는 항목

| 확인할 것 | 결과 |
|---|---|
| 이미지·아이콘의 `alt` | **미확인.** 부품이 그리므로 화면에서 판정할 수 없다 |
| 색만으로 정보를 전달하지 않는다 | **OK** |
| 포커스 순서가 시각 배열과 맞는다 | **미확인.** 정적 파일이라 탭 순서를 볼 수 없다 |
| 제목 레벨이 건너뛰지 않는다 | **OK** — 질문 제목이 `h1`, 섹션이 그 아래다 |
| 폼 요소에 `label` | **해당 없음.** 입력이 정렬 `Select` 하나뿐이다 |
| `lang` 과 페이지 제목 | **`lang="ko"` 있다.** 페이지 제목은 부품 밖이라 화면이 정한다 |

**대비·포커스·타겟 사이즈는 화면에서 고치지 않는다.** 미달을 찾으면 `DS-nn` 으로 기표한다([designer-workflow](../../../docs/guidelines/designer-workflow.md)).

## 부품이 못 따라가는 것 — 화면에서 우회하지 않았다

| `DS-nn` | 화면에서 어떻게 보이나 |
|---|---|
| `DS-23` | 답변 카드에 **「멘토 프로필 보기」 초록 버튼이 없다.** 액션이 인라인 아이콘이고, 채택 표시가 텍스트 배지다. 와이어는 박스 버튼 ＋ 초록 테두리다 |
| `DS-29` | 섹션 제목이 화면 제목과 같은 크기다 |
| `DS-30` | 해시태그가 회색이다. 와이어는 파란 계열이다 |

**답변별 스크랩은 넣지 않았다.** 와이어에는 있으나 **디자이너가 와이어 오류로 판정했다**(2026-09-14). 스크랩의 단위가 질문이라 한 질문에 여러 개가 동시에 켜진다.


**전부 그대로 두었다.** 부품 밖에서 비슷하게 그리면 나중에 두 벌이 된다. 디자인 시스템 개정은 **화면이 다 나오고 흐름이 보일 때 한 번에** 한다(2026-09-14 결정).
