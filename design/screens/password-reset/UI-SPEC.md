## 1. 화면의 사명

**비밀번호를 잊은 회원이 한 화면에서 끝낸다.** 메일로 인증 번호를 받아 인증하면 같은 자리에 새 비밀번호 칸이 열린다.

## 2. 대상 사용자와 상황

| 누가 | 언제 | 무엇을 원하나 |
|---|---|---|
| 비밀번호를 잊은 회원 | 로그인 실패 뒤 「비밀번호를 잊으셨나요?」 | 메일만 알면 끝 |
| 가입 안 한 사람 | 메일을 넣었는데 | 「가입되지 않은 메일」을 바로 알기 |

## 3. 액션 방침

| 판정 조건 | 아크션 |
|---|---|
| 이메일이 유효하다 | 「인증 번호 전송」 활성 |
| 가입되지 않은 메일이다 | 이메일 칸 아래 「가입되지 않은 메일 주소입니다.」 · 버튼은 secondary 그대로 |
| 전송했다 | `Toast` 「인증 번호를 전송했습니다」 · 타이머 03:00 → 내려감 · 버튼 「인증」 |
| 3분이 지났다 | 타이머 00:00 빨강 · 「인증 요청 시간을 초과했습니다.」 · 버튼 「인증 번호 재전송」 |
| 번호가 틀렸다 ／ 숫자가 아니다 | 「인증 번호가 일치하지 않습니다.」 ／ 「사용할 수 없는 문자열이 포함되어 있습니다.」 |
| **인증 완료** | 「인증 완료」 ＋ 체크 · `Toast` 「메일이 인증되었습니다」 · **새 비밀번호 2칸이 선다** |
| 24시간 5회를 넘었다 | 「오늘 인증 요청 횟수(5회)를 넘었습니다. 24시간 뒤에 다시 시도해주세요.」 · 전송 disabled |
| 재전송 | 전송 뒤 5분 동안 disabled ＋ 툴팁 「5분 뒤에 다시 보낼 수 있어요」 |
| 새 비밀번호 2칸이 같다 | 「비밀번호 재설정하기」 활성 → `password-done` |
| 이메일을 고쳤다(인증 뒤) | `before` 로 되돌아감 |

## 4. 구성과 하이어라키

| 순 | 블록 |
|---|---|
| 1 | h0 「비밀번호를 잊으셨나요?」 → `--green-50` 원 120 ＋ 아이콘 lock-key(일러스트 자리 · §11 8) → body 2줄 안내 |
| 2 | `Field` 이메일 → **`OtpField`**(`DS-122`) |
| 3 | `otp=verified` 일 때만 `Field` 「새 비밀번호 설정」(눈 토글 · 규칙 caption) ＋ `Field` 「새 비밀번호 확인」 |
| 4 | `primary` 100% 「비밀번호 재설정하기」 → 「비밀번호가 기억나셨나요? 로그인」 |
| 완료 | 원 ＋ checkmark-circle-02 → h0 「비밀번호 재설정을 완료했습니다.」 → `primary` 100% 「로그인」 → 글자 링크 「톱 화면으로 가기」 |

## 6. 블록별 규칙 (구성 요소 포함) — 인증 번호 칸 상태 8 (정본)

보드 `1178:56289` 그대로. `signup` 도 이 표를 쓴다.

| `otp` | 입력 칸 | 타이머 | 버튼 | 아래 글자 |
|---|---|---|---|---|
| `before` | disabled · 「인증 번호 6자리」(3판 · 검수 2차 ⑦) | 03:00 muted | `secondary` 「인증 번호 전송」 → 이메일 유효하면 `primary` | (미가입이면 이메일 칸 아래 「가입되지 않은 메일 주소입니다.」) |
| `sent` | 활성 | 02:31 ↓ | 「인증」 `secondary` → 6자리면 `primary` | — |
| `verified` | 읽기 전용 「123456」 | 숨김 | `secondary disabled` 「인증 완료」 ＋ 체크 | — |
| `timeout` | 활성 | 00:00 `--destructive` | `primary` 「인증 번호 재전송」 | 「인증 요청 시간을 초과했습니다.」 |
| `mismatch` | 「123456」 destructive · 테두리 destructive | 02:31 | 「인증」 `primary` | 「인증 번호가 일치하지 않습니다.」 |
| `invalid` | 「1234A#!r가」 destructive | 02:31 | 「인증」 | 「사용할 수 없는 문자열이 포함되어 있습니다.」 |
| `unregistered` | disabled | 03:00 | `secondary` | 이메일 칸 아래 「가입되지 않은 메일 주소입니다.」 |
| `limit` | disabled | — | `disabled` 「인증 번호 전송」 | 「오늘 인증 요청 횟수(5회)를 넘었습니다. 24시간 뒤에 다시 시도해주세요.」 |

**2판 값**(2026-10-15) — 입력칸 오른쪽 64 가 타이머 자리다. 자리글은 말줄임으로 끝난다. 버튼 폭은 PC 120 고정이다. 390 에서는 104 에서 시작해 글자 폭만큼 136 까지 늘어난다(측정 104 〜 118). 자리글 끝과 타이머 사이는 전 상태에서 15.
