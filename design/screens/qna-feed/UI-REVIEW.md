## 375px 는 iframe 으로 쟀다

**headless Chrome 은 창 최소 폭이 500px 다.** `--window-size=375` 를 주면 레이아웃은 500 인 채 **스크린샷만 잘려** 가짜 넘침이 된다.

375 폭 `iframe` 을 420 창 안에 넣어 **진짜 375 뷰포트**를 만들어 다시 쟀다. [design-bolt](../../../.claude/skills/design-bolt/SKILL.md) 가 경고한 함정이다.

## 부품이 못 따라가는 것 — 화면에서 우회하지 않았다

| `DS-nn` | 화면에서 어떻게 보이나 |
|---|---|
| `DS-27` | `Pagination` 이 `1 2 3 … 12` 로 뜬다. 와이어는 `1 2 3 4 5 6 7 … 12` 다 |
| `DS-28` | 「답변 완료 / 기다리는」이 왼쪽 작은 세그먼티드다. 와이어는 본문 폭 2등분 ＋ 밑줄 |
| `DS-29` | 섹션 제목이 화면 제목과 같은 크기다 |
| `DS-31` | 우측 위젯에 **테두리 박스가 없다.** 「나의 Q&A멘토링」·「주목받는 태그로 찾기」는 박스 없이 섰다. **질문 유도 CTA 만 카드 토큰을 인라인으로 적어 박스를 그렸다** — 이 감사에서 손으로 그린 유일한 1건이다 |


**`DS-27`·`DS-28`·`DS-29` 는 그대로 두었다.** 부품 밖에서 비슷하게 그리면 나중에 두 벌이 된다. **`DS-31` 의 CTA 박스만 이미 그려져 있다** — 판정이 나면 부품으로 바꾼다. 디자인 시스템 개정은 **화면이 다 나오고 흐름이 보일 때 한 번에** 한다(2026-09-14 결정).
