# mentor-search — UI-REVIEW

- 대상: `template/` 4상태 (2026-09-13 판)
- 대응 UI-SPEC: `bec4829`
- 어떻게 봤나: **Chrome headless 로 4상태를 1440 에서 렌더**하고 `768` 을 추가로 봤다. **렌더된 DOM 도 덤프해서 셌다**

**판정: NG.** 블로커 2건이다. 나머지는 UI-SPEC 대로 나왔다.

## 🔴 블로커 — 2건

### 1. 반응형이 없다

`grid-template-columns: **repeat(4, 296px)**` 가 **3파일에 고정으로 박혀 있고 `@media` 가 0건**이다.

**768 에서 4열을 그대로 밀어 3번째 카드부터 화면 밖으로 잘린다.** 가로 스크롤이 생긴다.

UI-SPEC §6 은 **「1280＋ 4열 / 767 · 390 2열」**이다. 6품질축의 **반응형**(「폭을 좁혀도 가로 스크롤·요소 붕괴가 없다」)에도 걸린다.

**재생성이 필요하다.** 레이아웃·구조 레벨이라 여기서 고치지 않는다.

### 2. 걸린 조건 칩에서 조건을 뺄 수 없다

`Chip` 에 `onRemove="{{ onClearCountry }}"` 를 넘겼고 `onClearCountry` 도 스크립트에 정의돼 있는데, **렌더된 DOM 에 `mt-chip-remove` 버튼이 없다.** 칩이 표시 전용 `<span>` 으로 나온다.

UI-SPEC §6 은 **「`Chip` `md` ＋ `onRemove`」**다. **지금은 「필터 초기화」로 전부 지우는 길밖에 없다.**

## 🟡 UI-SPEC 을 고쳐야 하는 것 — 1건

### 3. 걸린 조건 칩이 축 단위다

실물은 **「일본 외 2」 「마케팅」** 두 개다. 트리거가 이미 「일본 외 2」인데 **아래 칩이 같은 말을 되풀이한다.**

**낱개여야 뺀다** — 「일본 ✕」「대한민국 ✕」「미국 ✕」. 「일본 외 2 ✕」를 누르면 셋이 한 번에 지워지고, 그것은 「필터 초기화」가 이미 하는 일이다.

**§6 이 「걸린 값」이라고만 써서 갈렸다.** UI-SPEC 을 **「축이 아니라 값 하나하나를 세운다」**로 고친다.

## 접근성 — 사람이 판정하는 항목

| 확인할 것 | 결과 |
|---|---|
| 제목 레벨이 건너뛰지 않는다 | `h1` 「멘토 찾기」 ＋ 결과 수가 그 아래다. **건너뜀 없음** |
| 정보를 색만으로 전달하지 않는다 | 걸린 조건이 **트리거의 채움 ＋ 아래 칩** 두 곳에 나온다 |
| 페이지에 `lang` 이 있다 | **미확인.** `template/` 은 4상태의 조각이고 `lang` 은 실장의 셸이 갖는다 |
| 폼 요소에 라벨 | `SearchInput` 이 `aria-label` 을 갖는다(부품 사양) |

**axe 자동 검사는 이 리포에 없다**([ADR-0005](../../../docs/adr/0005-design-team-deliverables.md)). 대비·타겟 사이즈의 미달은 `DS-nn` 으로 기표한다.
