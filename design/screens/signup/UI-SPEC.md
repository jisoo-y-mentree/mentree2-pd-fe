## 1. 화면의 사명

**회원이 되는 문이다.** 이메일이면 이름 · 이메일 인증 · 비밀번호 · 동의, 소셜 최초 로그인이면 이름 · 동의만 받고 온보딩 설문으로 보낸다.

## 2. 대상 사용자와 상황

| 누가 | 언제 | 무엇을 원하나 |
|---|---|---|
| 처음 온 사람(이메일) | 로그인 화면의 「신규 회원 가입」 | 한 화면에서 끝내기 |
| 처음 온 사람(소셜) | 소셜 버튼 → 계정 없음 | 이름과 동의만 하고 바로 |

## 3. 액션 방침

| 판정 조건 | 아크션 |
|---|---|
| **이름 · 인증 완료 · 비밀번호 2칸 일치 · 필수 3동의가 전부다** | 「회원 가입」 활성. 하나라도 빠지면 disabled |
| 소셜 모드에서 이름 ＋ 필수 3동의 | 「다음」 활성 |
| 「회원 가입」 · 「다음」 | `onboarding-survey?step=1` |
| 이메일을 고쳤다(인증 완료 뒤) | 인증이 풀려 `before` 로(보드 메모) |
| 「전체 동의」 | 4항목이 켜진다. 4항목을 다 켜면 전체 동의가 켜진다 |
| 「내용보기」 | `Dialog` 로 약관 본문(제목 ＋ 긴 본문 스크롤 ＋ 닫기) |

## 4. 구성과 하이어라키

셸은 로그인과 같다. h0 「신규 회원 가입」 가운데 → 폼(라벨 위 · 간격 24 · 4판). 입력하지 않으면 넘어갈 수 없는 칸은 `Field required`(＊ · 이름 · 이메일 · 인증 번호 · 비밀번호 2칸). 비밀번호 규칙은 `Field description`(라벨 아래).

| 모드 | 순 | 블록 |
|---|---|---|
| email | 1 | `Field` 이름 · `Field` 이메일 · **`OtpField`**(`DS-122`) · `Field` 비밀번호 설정(규칙 caption) · `Field` 비밀번호 확인(불일치 문구) |
| email | 2 | `ConsentGroup` — 전체 동의 → 1px 선 → 만 14세 이상(필수) · 이용 약관(필수 · 내용보기) · 개인정보(필수 · 내용보기) · 마케팅(선택) |
| email | 3 | `primary` 100% 「회원 가입」 → 「이미 회원이신가요? 로그인」 |
| social | 1 | caption 「구글 계정으로 처음 오셨네요. 이름과 약관 동의만 하면 끝나요.」 → `Field` 이름 → `ConsentGroup` → `primary` 100% 「다음」 |

## 8. 표시·활성 제어의 판정 조건과 아크션

| 판정 조건 | 아크션 |
|---|---|
| 이메일이 유효하다 | 「인증 번호 전송」 `primary` 로 |
| 6자리가 찼다 | 「인증」 `primary` 로 |
| 인증 완료 | 칸 읽기 전용 · 「인증 완료」 ＋ 체크 · 타이머 숨김 · `Toast` 「메일이 인증되었습니다」 |
| 비밀번호 확인이 다르다 | 칸 아래 destructive 「비밀번호가 일치하지 않습니다.」 |
| 필수 동의가 비었는데 버튼을 눌렀다 | 「필수 항목에 동의해주세요.」(버튼은 원래 disabled) |
