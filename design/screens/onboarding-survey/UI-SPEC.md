## 1. 화면의 사명

**추천의 입력값을 3스텝으로 받는다** — 커리어 단계 · 흥미 국가 · 흥미 직종 · 프로필. 매 스텝 건너뛸 수 있고 끝에 완료 화면이 선다. 커리어 단계(`Phase`)는 추천 입력값이지 진단 콘텐츠가 아니다([PRODUCT](../../../docs/PRODUCT.md)).

## 2. 대상 사용자와 상황

| 누가 | 언제 | 무엇을 원하나 |
|---|---|---|
| 방금 가입한 사람 | 가입 직후 | 빨리 끝내고 둘러보기. 건너뛰어도 됨 |

## 3. 액션 방침

| 판정 조건 | 아크션 |
|---|---|
| step 1 에서 카드를 하나 골랐다 | 「다음」 활성. 건너뛰기는 늘 가능 |
| step 2 · 3 | 「다음」 「완료」 늘 활성(선택 개수 제한 없음 · 최소 입력 없음 — 메모 Q2 · Q3) |
| 「건너뛰기」 | 그 스텝의 값 없이 다음 스텝 · 3스텝이면 완료 화면 |
| 「프로필 이미지 등록하기」 | `Dialog` 「프로필 사진 편집하기」 — `ImageCropper` ＋ 저장하기 |
| 완료의 「톱 화면으로」 | `top`(§11 5 · 10) |

## 4. 구성과 하이어라키

공통의 위아래가 같다. **`StepBar`**(`DS-121` · 막대 3 · 높이 6 · 간격 8 · 지난 것 ＋ 지금 것 `--primary` · 남은 것 `--sage-200`) → h0 「김민지 님에 대해 알려주세요」 → caption → 본문. 3스텝의 h0 는 「김민지 님의 프로필 정보를 등록해주세요」. 바닥은 `primary` 100% 「다음」(3은 「완료」) → `outline` 100% 「건너뛰기」.

| 스텝 | 본문 |
|---|---|
| 1 | 소제목 「당신의 해외 커리어에 대한 상황을 알려주세요」 → `RadioGroup` 을 카드 4장 2×2(안쪽 20 · 반경 12 · 선택하면 테두리 `--primary` ＋ `--green-50`) — 흥미 시작 · 본격 준비 · 출국 준비 · 해외 재직 |
| 2 | 「흥미있는 국가는 어디인가요? (복수선택 가능)」 → `FilterChip` 격자(`taxonomy.js` COUNTRY) → 「흥미있는 직종이 있다면 선택해주세요 (복수선택 가능)」 → `FilterChip` 격자(JOB) |
| 3 | caption 2줄 → `Avatar` 96(비면 이니셜) ＋ `ghost sm` 「프로필 이미지 등록하기」 → `Field` 「자기 소개 메시지」 `Textarea` 500 ＋ 카운터 |
| 완료 | `--green-50` 원 160 ＋ 아이콘 party → h0 「회원 가입이 완료되었어요」 → caption 2줄 → `primary` 100% 「톱 화면으로」 |

**768 이하**: 카드 1열 · 칩 줄바꿈 · 모달 전체 화면.
