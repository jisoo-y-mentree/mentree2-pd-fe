# UX-PATTERNS.md — 횡단 UX 패턴 (`P-nn`)

> 화면을 넘는 **UX 판단**을 담는다. 요소 하나의 규칙은 [DESIGN.md](DESIGN.md) 다.
> **`P-nn` 은 재사용하지 않는다. 행은 삭제하지 않는다.**

## 승격 규칙 (헌장 원칙 7)

| 판정 조건 | 아크션 |
|---|---|
| 그 판단이 **1화면**에서만 나왔다 | 그 화면의 `UI-SPEC.md` §6에 머무른다. **여기로 올리지 않는다** |
| 같은 판단이 **2화면째**에 나타났다 | **여기로 승격시킨다.** `P-nn` 을 붙이고, 양쪽 UI-SPEC 은 참조만 남긴다 |
| 승격 뒤에 예외가 나왔다 | 예외를 그 화면의 UI-SPEC 에 쓰고, 여기에는 예외가 있다는 사실만 적는다 |
| 쓰이지 않게 되었다 | 행을 남긴 채 **종단**으로 닫는다(취하·각하) |

**2회 실증을 기다리는 이유**: 1회로 승격시키면 그 화면의 사정이 전 제품의 규칙이 된다.

### 1회 실증으로 올라오는 것 — 헌장이 정한다

**근거가 외부 참조원이면 1화면째에 올린다.** 이것은 이 문서의 예외가 아니라 [DESIGN-CHARTER](DESIGN-CHARTER.md) **원칙 7 자체의 조건**이다. 심사받는 문서가 심사 기준에 예외를 만들 수 없으므로 헌장을 개정했다.

| 판정 조건 | 아크션 |
|---|---|
| 판단의 근거가 **외부 참조원**이다 | **1화면째에 올린다.** 「참조원」 열을 반드시 채운다 |
| 판단의 근거가 **우리 화면의 사정**이다 | **2화면째**를 기다린다 |
| 1화면인데 참조원 열이 비어 있다 | **올리지 않는다.** 헌장 원칙 7의 운용 테스트가 이것을 잡는다 |

## 참조원 — 바퀴를 재발명하지 않는다

**B2C 의 로그인·가입·결제·일정 조율은 이미 풀린 문제다.** 와이어를 처음부터 화면으로 옮기지 않고 표준을 가져온다.

### 무엇을 가져오고 무엇을 안 가져오는가

| 가져온다 | 가져오지 않는다 |
|---|---|
| **플로우의 순서와 상태 전이**(UI-SPEC §9) | 문구·톤 |
| **판정 조건과 에러 처리**(§8) | 비주얼·색·간격 |
| **4상태의 구성**(§7) | 제품 고유의 판단(§1~5) |
| **키보드·포커스·ARIA** | 정보 구조 — 무엇을 보여줄지 |

**「어떻게 동작하는가」는 빌려오고, 「무엇을 보여줄까」는 우리가 정한다.**

### 참조원과 담당

| 참조원 | 누가 가져오나 | 무엇을 |
|---|---|---|
| **WAI-ARIA APG** | Claude | 패턴별 키보드·ARIA 명세. §8 로 직결된다 |
| **shadcn/ui Blocks** | Claude | 레이아웃 블록의 구조. `ds-export` 의 토대와 같다 |
| **Base UI / Radix** | Claude | 인터랙션 상태 기계. 헤드리스라 비주얼을 끌고 오지 않는다 |
| **Mobbin · 실서비스** | **디자이너** | 화면 착수 시 **레퍼런스 3~5장**. AI 는 로그인이 필요한 도구를 볼 수 없다 |

**미리 다 모으지 않는다.** 화면 하나 시작할 때 3~5장이면 된다. 안 쓰는 참조가 쌓이면 문서가 무거워진다(헌장 원칙 2).

### ⚠ 참조원은 전제를 함께 가져온다

**우리 제품의 전제와 충돌하는 지점이 있다**([PRODUCT.md](../docs/PRODUCT.md) 「제품의 전제」).

| 전제 | 어디서 깨지나 |
|---|---|
| **시간대가 둘이다**(멘토·멘티) | 일정 조율 패턴 대부분이 단일 시간대를 가정한다. 와이어는 「멘토 시간대: 12:00~12:30」을 병기한다 |
| **한/일 이중언어** | 문구 길이가 2배로 늘 수 있다. 고정폭 레이아웃을 그대로 쓰면 깨진다 |
| **통화가 USD 다** | 국내 결제 패턴(원화·간편결제)을 그대로 쓸 수 없다 |

| 판정 조건 | 아크션 |
|---|---|
| 참조 패턴이 위 전제와 충돌한다 | **UI-SPEC §11「미결」에 적는다.** 참조를 그대로 쓰지 않는다 |

**세 건은 2026-09-12 에 `mentor-search` 가 2화면째로 실증하면서 올라왔다.** `qna-feed` 가 1화면째에 「미승격」으로 세 건을 적어두고 「`mentor-search`·`insight-list` 에서 다시 나올 것」이라고 예고했고, 와이어의 주석 6건이 셋 다 확인해 줬다.

**참조원 열은 비어 있다.** 셋 다 **우리 화면의 사정**에서 나왔고 2화면 실증으로 올라왔다(헌장 원칙 7의 기본 경로).

| 판정 조건 | 아크션 |
|---|---|
| `insight-list`·`notice-list` 를 만든다 | **이 셋을 먼저 읽는다.** 목록 화면이면 전부 걸린다 |
| 이 패턴에 안 맞는 목록 화면이 나왔다 | **예외를 그 화면의 UI-SPEC 에 쓰고, 여기에는 예외가 있다는 사실만 적는다** |
